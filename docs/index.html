The AI industry

Anthropic launches Claude Duet, a background AI agent that messages you when it matters

Built on the Opus 5.5 model, Duet joins Meta's Muse and OpenAI's Dots in a fast-growing race to build AI agents that work unsupervised.

Anthropic has released Claude Duet as a 'research preview', a personal AI agent aimed at professionals and small business owners that runs quietly in the background. Rather than waiting to be asked, it sends a morning briefing summarising what matters across your connected apps, then only interrupts you when something needs attention.

Duet is built on Anthropic's Opus 5.5 model and can be handed tasks ranging from scheduling meetings to building financial forecasts, dashboards and prototype web apps. It uses a virtual machine, essentially a simulated computer the AI can control, complete with its own browser, to carry out multi-step work on your behalf. Before anything risky, such as sending a payment or deleting a file, it messages you for approval first.

Because Duet may handle sensitive information, Anthropic has added a dedicated safety classifier, a filter that screens outputs, and a system prompt, hidden instructions that shape how the model behaves, both designed to stop it sharing things like credit card numbers. Anthropic admits the early version can still misjudge urgency or misread messages.

The launch intensifies a three-way contest with Meta's Muse, which hit 10 million US downloads this week, and OpenAI's Dots. Access to Duet is currently limited to Pro and Max subscribers in the US via a waitlist, but it signals that the next phase of the AI race is about agents doing jobs, not just answering questions.

Sources: The Verge · The Verge · The New York Times

Key concepts in this story
AI agent
An AI agent is a system that can take multi-step actions on its own, like booking a meeting or building a spreadsheet, rather than just replying to a single question.
Virtual machine
A virtual machine is a software-simulated computer that an AI agent can control, including its own browser, so it can click, type and navigate the web the way a person would.
Context window
The context window is how much text and information an AI model can 'hold in mind' at once; an agent that monitors your apps all day needs a model that can track a lot of ongoing information without forgetting earlier details.
Safety classifier
A safety classifier is a filter that scans what an AI is about to say or do and blocks sensitive content, such as stopping an agent from revealing someone's credit card number.
Why it matters for you

Companies are now racing to hire people who can design, test and set guardrails for autonomous agents, not just prompt a chatbot. If you're interviewing for an AI role, being able to explain the difference between a chatbot and an agent that takes real-world actions (and the approval steps needed to keep it safe) is an easy way to stand out.

The AI industry

AI models help uncover 'PHP2Shell', a critical flaw in code running much of the web

Google, OpenAI and Amazon used AI systems to find and respond to vulnerabilities in PHP, prompting government warnings worldwide.

Security researchers have disclosed two critical vulnerabilities, dubbed PHP2Shell, in PHP, an open-source programming language that underpins a huge share of websites and web applications. The flaws could let attackers remotely run malicious code on affected servers, potentially exposing sensitive data and databases, triggering urgent alerts from agencies including the US National Security Agency, the FBI, and authorities in the UK, Singapore, Australia, Canada and the EU.

Notably, AI played a central role in finding and fixing the problem. Google said its cybersecurity unit Wiz used AI models, including its Gemini system, to help investigate the vulnerabilities and test patches. OpenAI said researchers working with its models had also helped uncover the flaws, and spent two months coordinating a response with software maintainers and security firms before public disclosure. Amazon said its MadPot threat-detection system had already spotted exploitation attempts before the flaws were announced.

Cloudflare has rolled out protections through its web application firewall, a system that filters malicious web traffic, while the PHP team has released official fixes. Authorities are urging website operators to identify affected versions and patch immediately, or take systems offline if they can't.

The episode is being held up as a case study in AI's double-edged role in cybersecurity: the same pattern-spotting abilities that helped researchers find PHP2Shell before criminals could exploit it widely could just as easily be turned towards discovering new vulnerabilities by attackers.

Sources: Tech · The New York Times · Axios

Key concepts in this story
Zero-day vulnerability
Reminder: a zero-day vulnerability is a security flaw that's exploited before developers have had any chance to fix it, leaving defenders with zero days' notice.
Remote code execution
Remote code execution means an attacker can run their own commands on someone else's computer or server over the internet, essentially taking control without physical access.
Open source
Reminder: open-source software has its underlying code published publicly, so anyone can inspect, use or modify it, which is why a flaw in widely-used open-source code like PHP can affect millions of websites at once.
Why it matters for you

This shows a concrete, paid use case for AI beyond chatbots: automated vulnerability discovery and patch testing, a fast-growing niche for security engineers who can work alongside AI tools. In an interview, you could point to PHP2Shell as an example of AI being used defensively, not just as a risk.

The AI industry

Meta creates new non-voting share class to fund AI spending of up to $145bn

The new Class C stock, trading from 2027, will help pay for data centres, acquisitions and staff as Meta's AI costs keep climbing.

Meta announced in its third-quarter earnings that it will issue a new class of non-voting shares to help fund its AI push, with trading due to begin in 2027. The company said the money raised could go towards acquisitions and employee pay, as well as its core AI infrastructure build-out.

Meta's chief financial officer Susan Li said the new share class would give the company 'flexibility' to invest behind what she called unprecedented momentum across its business. Meta now expects capital expenditure, the money spent on long-term assets like data centres and chips, to hit between $135 billion and $145 billion this year, up from its earlier estimate, as it competes with rivals including OpenAI for talent and computing power.

The funding news comes weeks after Meta launched its own AI agent, Muse, which reached 10 million US downloads within weeks. Muse's rollout hasn't been smooth: a YouTuber reported the agent disclosed his address to a stranger on Facebook Marketplace, and Meta had to pause a feature that let conversations be shared after some chats turned up publicly online.

The new share class underlines just how expensive the AI race has become, with Meta turning to fresh financial instruments, not just cash on hand, to keep pace. Investors will be watching whether the additional funding leads to clearer returns, or simply higher spending with uncertain payoff.

Sources: The Verge · Financial-News.co.uk · Startup Fortune

Key concepts in this story
Share class
Companies can issue different classes of stock with different rights; a non-voting share class lets a company raise money from investors without giving them a say in how it's run, unlike ordinary shares.
Capital expenditure (capex)
Reminder: capex is money spent on long-term physical assets, like data centres and chips, as opposed to day-to-day running costs.
Acquisition
Reminder: an acquisition is when one company buys another outright, often to gain its technology, staff or customers quickly rather than building them in-house.
Why it matters for you

Understanding how tech giants finance AI, not just how much they spend, matters for anyone eyeing finance or strategy roles at these firms. It also links to today's Barclays story: both are about the huge cost of AI infrastructure and how companies choose to pay for it.

AI & finance

Barclays to cut 5,000 jobs by end of 2026 in AI-driven efficiency push

The bank is leaning on automation to cut costs, part of a wider trend the Federal Reserve is watching closely across the sector.

Barclays has confirmed it will cut around 5,000 jobs by the end of 2026 as it increases its reliance on artificial intelligence to streamline operations and reduce costs. The cuts span the bank's operations, with reports suggesting roles in the UK, including Scotland, will be affected.

Banks have been among the earliest adopters of AI tools for back-office work such as processing transactions, flagging fraud and handling routine customer queries, tasks that previously required large teams of staff. Barclays' move follows a broader pattern across the financial sector of using AI to automate repetitive work, even as regulators and economists debate how quickly, and how far, this kind of automation will spread through the job market.

The announcement comes as the US Federal Reserve has itself been commenting on AI's effect on employment, amid growing scrutiny of whether AI-driven job cuts across the finance industry are a one-off cost-cutting exercise or the start of a longer structural shift.

For workers, the move highlights how AI is reshaping entry-level and mid-career banking roles, pushing demand towards staff who can build, manage or oversee automated systems rather than perform the manual tasks AI now handles.

Sources: BBC · Bdaily · Sky News

Key concepts in this story
Automation
Automation means using technology, including AI, to perform tasks that previously needed a human, such as processing routine transactions or answering standard customer questions.
Federal Reserve
Reminder: the Federal Reserve is the US central bank, responsible for setting interest rates and monitoring risks to the economy, including how new technology affects jobs and inflation.
Technological unemployment
Technological unemployment describes job losses caused specifically by machines or software replacing tasks people used to do, as opposed to a broader economic downturn.
Why it matters for you

If you're starting a career in finance, this is a clear signal to build skills in managing, auditing or improving AI systems rather than competing with them on routine tasks. It's a good talking point in interviews: show you understand AI as a tool reshaping job descriptions, not just a threat.

Anthropic reportedly set to file for IPO as early as Friday at up to $2 trillion valuation

Draft filings reportedly show a $450 billion cloud computing commitment and an $80 billion loss ahead of a potential market debut.

Anthropic is reportedly preparing to publicly file for an initial public offering, or IPO, the process of selling shares to public investors for the first time, as soon as Friday. Sources cited by Yahoo Finance suggest the AI company could seek a valuation of up to $2 trillion.

According to reports on a draft filing, Anthropic has committed $450 billion to cloud computing, the rented computing power it needs to train and run its AI models, while also reporting an $80 billion loss. Such losses are common for fast-growing AI labs pouring money into compute and talent well ahead of matching revenue, but the scale underscores just how costly building frontier AI models has become.

The reported move comes amid wider uncertainty about AI valuations: one report suggested OpenAI's own IPO ambitions could be complicated by a potential distressed sale of assets to Microsoft, while analysts have been pointing investors towards public companies with AI exposure as an alternative to buying into private AI labs directly.

If Anthropic does file, it would be one of the largest technology IPOs in history, testing investor appetite for AI companies that are burning enormous amounts of cash while chasing long-term dominance in the field.

Sources: Yahoo Finance · Crypto Briefing · 24/7 Wall St.

Key concepts in this story
IPO (initial public offering)
Reminder: an IPO is when a private company sells shares to the public for the first time, usually to raise money and let early investors cash out.
Net loss
A net loss means a company spent more money than it brought in over a period; Anthropic's reported $80 billion loss reflects heavy spending on computing power and staff versus current revenue.
Compute deal
Reminder: a compute deal is an agreement to buy or reserve computing power, often from cloud providers, to train and run AI models; Anthropic's reported $450 billion commitment shows how costly this has become.
Why it matters for you

A potential $2 trillion IPO would be one of the biggest tests yet of whether public markets believe AI labs' spending will eventually pay off. Anyone tracking fintech or markets should watch this alongside Meta's new share class today, both are signs of how AI's costs are being pushed onto investors.

LSEG agrees $3.5bn deal to acquire credit data firm Octus

The London Stock Exchange Group is buying Octus in a cash acquisition to expand its data business.

The London Stock Exchange Group (LSEG) has agreed to acquire Octus, a provider of credit data, in a cash deal worth $3.535 billion. Octus specialises in data covering credit markets, information used by investors and analysts to assess how risky it is to lend to a particular borrower.

The acquisition adds to LSEG's growing portfolio of data and analytics businesses, reflecting a wider trend of financial exchanges and data providers buying up specialist data firms to offer clients more comprehensive market information in one place.

Full details of the rationale and integration plans were not disclosed in initial reporting, but the deal size signals how valuable credit market data has become as investors try to price risk more precisely across both public and private debt markets.

Sources: Finextra Research Headlines

Key concepts in this story
M&A (mergers and acquisitions)
Reminder: M&A describes deals where companies combine or one buys another; here LSEG is acquiring Octus outright in an all-cash transaction.
Credit data provider
A credit data provider collects and sells information about how likely borrowers are to repay debt, helping investors decide how much risk they're taking on when they lend money or buy bonds.
Why it matters for you

Data has become one of the most valuable assets in finance, and this deal shows exchanges are willing to pay a premium for specialist datasets rather than build them in-house. It's a useful example if you're asked in an interview why data and analytics roles are growing inside traditional financial institutions.

Startups & funding

Legal AI firm Legora raises $550m Series E at $8.8bn valuation

The Swedish startup's valuation has nearly doubled in six months as it races rival Harvey in the booming legal AI market.

Legora, a Swedish startup building AI tools for legal professionals, has raised a $550 million Series E funding round, valuing the company at $8.8 billion. The round was led by Atreides Management, with participation from Baron Capital, Bessemer Venture Partners, General Catalyst and Menlo, among others.

The jump is striking: Legora's valuation stood at $5.6 billion back in April, when it closed a $50 million extension to its Series D round. Since then its annual recurring revenue, the predictable yearly income a subscription business expects to keep collecting, has doubled from $100 million to over $200 million, fuelling the new, higher valuation.

Legora sits in the fast-growing niche of vertical AI, products built for a specific industry rather than general use, here helping lawyers with tasks like contract review and research. Its closest rival, Harvey, raised $550 million at a $15.5 billion valuation just a month ago, having already reported ARR above $200 million back in March, making this one of the most heavily funded corners of enterprise AI.

Legora says it will use the new capital to expand further into North America, as both it and Harvey push to convince law firms that AI tools, not just more junior lawyers, can handle a growing share of legal work.

Sources: TechCrunch · Reuters · Quartz

Key concepts in this story
Series E
Reminder: a Series E round is typically a late-stage startup funding round, raised by companies that are already well established and scaling fast, rather than early-stage experimentation.
Annual recurring revenue (ARR)
Reminder: ARR is the predictable yearly revenue a subscription business expects, like a law firm paying $200,000 a year for software access, used by investors to judge how fast a company is really growing.
Up round
An up round is a new funding round at a higher valuation than the company's previous round, showing investors believe the business has grown more valuable, as with Legora rising from $5.6bn to $8.8bn in six months.
Why it matters for you

Legal AI is one of the clearest examples of 'vertical AI' making money today, showing how AI companies can succeed by going deep into one industry rather than competing head-on with giants like OpenAI. If you're exploring AI careers beyond the big labs, vertical AI startups like Legora are hiring for both engineering and domain-expert roles.

Startups & funding

Year-old AI lab Flapping Airplanes raises $1bn at $6bn valuation

The young research startup's mega-round shows investors are still willing to bet big on new AI labs barely a year old.

Flapping Airplanes, an AI research lab that is only about a year old, has raised $1 billion in new funding at a $6 billion valuation, according to reports. Details of the round, including which investors took part and what specifically the company is building, were not fully disclosed.

The scale of the raise, a billion dollars for a company still in its first year, illustrates how much capital continues to flow into AI labs even as questions mount elsewhere about whether AI valuations are overheated. Investors appear willing to place large early bets on research teams they believe could develop valuable models or techniques, well before any clear product or revenue exists.

With limited public detail available, it isn't yet clear what Flapping Airplanes' technology does or how it plans to compete with established frontier AI labs. The size of the round alone makes it one of the more eye-catching startup deals of the week.

Sources: TechCrunch · Quartz · Bloomberg.com

Key concepts in this story
Mega-round
A mega-round is startup slang for an unusually large funding round, often $500 million or more, reflecting investors making a big, concentrated bet on one company.
Frontier AI lab
Reminder: a frontier AI lab is a company working at the cutting edge of AI capability, racing to build the most advanced models, which is expensive and attracts very large funding rounds.
Why it matters for you

This shows that despite talk of an AI bubble, investors are still funding very young, unproven AI labs at enormous valuations. It's worth tracking whether companies like this can justify their valuations with real products, a useful lens for judging any AI startup pitch you come across.

Code corner

Simulating an AI agent's tool-call approval request

Based on: Anthropic launches Claude Duet, a background AI agent that messages you when it matters

Claude Duet messages you for approval before taking a risky action, like sending a payment. Real AI agents often communicate with the apps around them using structured JSON, a text format for organised data. Here's a simplified, fake example of what an agent's request for approval might look like before it calls a 'send_payment' tool.

import json

# Simulate what an AI agent might send when it wants to take a risky action
agent_request = {
    "agent": "Claude Duet",
    "action": "send_payment",
    "details": {
        "amount": 120.50,
        "currency": "GBP",
        "recipient": "Acme Office Supplies"
    },
    "requires_approval": True
}

# Convert the Python dictionary into a JSON string, like an API would
request_json = json.dumps(agent_request, indent=2)
print("Agent request:")
print(request_json)

def review_request(request: dict) -> str:
    if request.get("requires_approval"):
        amount = request["details"]["amount"]
        recipient = request["details"]["recipient"]
        return f"Approval needed: pay {amount} to {recipient}?"
    return "No approval needed, agent can proceed."

print("\nHuman sees:")
print(review_request(agent_request))
Line by line
  1. import json loads Python's built-in library for converting between Python dictionaries and JSON text, the format most APIs use.
  2. agent_request is a Python dictionary describing the action the agent wants to take, including an amount, currency and recipient, mirroring how a real agent might structure a tool call.
  3. json.dumps() turns that dictionary into a formatted JSON string, the kind of message an app might actually send over the internet; indent=2 just makes it readable.
  4. review_request() checks the requires_approval flag and builds a human-readable message, standing in for the approval prompt Claude Duet would show you before sending a payment.
  5. The final print statements show first the raw JSON an API would exchange, then the simplified message a human actually sees.

Try it: Add a new field called 'risk_level' (e.g. 'low', 'medium', 'high') to agent_request, then update review_request() so it only asks for approval when risk_level is 'high', printing 'No approval needed' otherwise.
